# Trajectory Optimization with acados
This is a Python-based acados wrapper for convenient multi-phase and multi-dynamics switched systems.

# Dependencies
1. casadi
2. pinocchio (>= 3.0)
3. typeguard
4. numpy
5. acados_template
6. pprint (optional)
